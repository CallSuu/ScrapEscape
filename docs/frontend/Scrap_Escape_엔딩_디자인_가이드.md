# 엔딩 디자인 초안

성공: static/assets/endings/success.png, 실패: failed.png. imagegen으로 제작한 비행기 탈출/숲속 잔류 장면을 result.css의 상단 hero 배경으로 표시한다. 오른쪽에 어두운 그라데이션을 겹쳐 제목·사유·소요 시간을 읽도록 한다. 질병 실패와 시간 초과는 같은 실패 이미지를 쓰고 정확한 사유는 기존 서버 값으로 표시한다.

21개 통계와 수리 목록·새 게임 기능은 유지한다. 낮은 화면에서는 배너와 통계 간격을 줄인다. 이미지는 같은 이름으로 교체하고 구도는 background-position으로 수정할 수 있다. 실제 브라우저의 스크롤과 배치는 별도 확인이 필요하다.
