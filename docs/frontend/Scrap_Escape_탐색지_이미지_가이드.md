# 탐색지 이미지 초안

장소별 전용 이미지는 static/assets/locations/location-1.png~location-6.png에 보관한다. 순서는 고물상, 전자제품 매장, 마트, 정비소, 통신 시설, 병원이다. imagegen으로 생성한 오염 도시의 실사풍 배경이며 인물·UI·문구 없이 건물과 주변 사물로 장소를 구분한다.

수색 상세 창(exploration.mjs), 탐색 결과 및 방 발견 화면의 장소 배경(main.mjs)이 같은 파일을 사용한다. 원래의 도시 지도 버튼 배경은 city-district.png를 유지한다. 전용 사진에는 기존 지도 확대(scale3)를 적용하지 않는다. 이전 SVG는 보존했다.

수정 시 같은 파일명을 유지하면 두 화면에 함께 반영된다. 이미지 안에 장소 이름을 넣기보다는 HTML 제목을 사용한다. 브라우저 전체 배치 검증은 별도 필요하다.
