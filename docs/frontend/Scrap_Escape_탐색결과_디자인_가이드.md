# 탐색 결과 디자인

exploration-result.mjs/CSS에 완료 제목·장소명·전리품 카드·결과 안내·확인 버튼을 구성했다. 재료는 황동색(미세척), 세척액/키트/열쇠는 청록색 카드다. 공통 SVG 아이콘과 큰 수량을 표시하고 이름의 중복 수량 표시는 제거했다. 일반 탐색과 방 개방의 제목을 구분한다.

장소별 배경을 유지하며 결과 패널에 어두운 반투명 배경을 적용한다. 남겨둔 재료·보유 한도는 황색, 손실은 붉은 강조선으로 표시한다. 빈손 결과도 정상 결과이며 확인 흐름은 기존 Context 명령을 사용한다. 확률·보상·API는 바꾸지 않았다.

검증: JavaScript74개 통과, bootJar 성공. Chrome1280×720/1440×900/1920×1080에서 최대5카드/빈손/손실9개 조합의 패널 스크롤·확인 버튼 잘림 없음, 이미지 decode 성공, 확인 명령 실행 및 JS예외0 확인. 매우 긴 예외 안내는 상세 영역 내부 스크롤로 접근할 수 있게 유지한다. work/receipt-browser.log와 receipt-*.png는 로컬 검증 자료다.


배경 수정: exploration-result에서는 /assets/locations/scavenge-result.png 전용 수집품 정리 공간을 사용한다. 기존 임시 SVG 연결을 제거했다. 비밀의 방은 장소별 location-N.png를 사용한다. 결과 패널은 배경을 볼 수 있도록 투명도를 조정하며 아이템 카드는 기존 가독성을 유지한다. 전용 배경은 모든 탐색 결과에서 공통 사용하며 장소 이름은 제목으로 구분한다.
