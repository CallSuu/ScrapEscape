# 아이템 아이콘 초안

재료10종과 세척액·의료 키트·열쇠13종의 SVG를 assets/items에 보관한다. 64×64 좌표, 투명 배경, 금속색과 황동색 선을 사용한 기초 디자인이다. 파일을 같은 이름으로 교체하면 공통 모듈을 사용하는 인벤토리·보관함·보상·정비 목록에 적용된다.

연결: static/js/item-icons.mjs의 itemIconPath 및 itemIcon. 재료ID1~10은 metal/gear/wire/circuit/plastic/rubber/battery/filter/alloy/signal 순서다. 보급품은 cleaner/medical/key다. 이름·수량·상태 텍스트를 유지하고 장식 이미지는 빈 alt를 사용한다. 세척 상태와 선택 강조는 기존 테두리로 유지한다.

이번 단계는 수정 가능한 벡터 초안이다. 장소별 이미지와 엔딩 배경은 다음 단계다. JavaScript74개 검증 통과. 실제 브라우저의 슬롯 높이와 전체 배치 검증은 별도 필요하다.

## 재질·입체감 개선

기존 단색 도형을 수정해 금속의 밝은 절단면과 어두운 측면, 철 조각의 녹, 황동 기어, 구리 전선의 피복과 노출 도체, 회로 칩·배선·접점, 타이어 홈, 필터 주름을 추가했다. 플라스틱은 베이지, 배터리는 녹색, 세척액은 청록색, 키트는 붉은 십자로 구분한다. 투명 배경64×64 SVG와 기존13개 파일명/연결 방식은 유지했다.

Chrome에서90·40·28px 아이콘 비교 시트를 렌더링해 육안 확인했다(work/refined-icons-preview.png). SVG13개 XML 파싱과 JavaScript75개 통과. 이번 작업은 아이콘 파일 변경이며 화면 배치·API·게임 규칙은 변경하지 않았다. 게임 전체 화면을 다시 실행한 검증은 포함하지 않는다.


캐시 갱신: 공통 itemIconPath는 SVG 주소에 ?v=20261109를 붙인다. 아이콘 갱신 시 이 버전을 함께 변경한다. 실행 중8080에서 기어 SVG 응답과 수정 소스의 SHA-256 일치를 확인했다. 현재 페이지에 이미 로드된 JavaScript는 강력 새로고침으로 갱신해야 한다. 서버/게임 데이터는 재시작하거나 변경하지 않았다.
