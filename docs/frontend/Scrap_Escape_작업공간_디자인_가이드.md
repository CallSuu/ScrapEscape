# 안전지대 작업 공간 디자인 초안

보관함·세척·휴식·치료는 safe-zone.css에서 녹색 금속 패널·황동색 선택 강조·청록색 세척 완료 표시를 공유한다. 세척/휴식은 녹색, 치료는 청록, 폐기는 갈색 계열로 구분한다. 선택 표시와 CLEAN 테두리는 별개로 유지한다. 미리보기는 왼쪽 강조선이 있는 안내 영역으로 표시한다.

휴식 제목은 달 표시, 치료 제목은 기존 의료 키트 SVG를 사용한다. 작은 화면에서 기존 3열 보관함과 2열 휴식/치료 배치를 유지한다. fixed HUD 크기는 변경하지 않는다. 실제 화면 높이와 스크롤은 브라우저에서 추가 확인해야 한다.

교체 위치: static/css/safe-zone.css의 Camp workspaces 주석 이하. 동작·비용·확률·API는 변경하지 않는다.
