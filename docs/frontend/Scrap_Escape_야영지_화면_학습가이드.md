# 숲속 야영지·항공기 정비 화면

현재 배치 변경: 탐색은 도시 건물→지역 정보 창→선택하기, 모달은 어두운 배경과 넓은 콘텐츠 높이를 사용한다. [최신 안내](Scrap_Escape_도시선택_창배치_학습가이드.md).


## 현재 화면 흐름

메인 → **안전지대 전체 화면(숲속 야영지)**.

| 배경 속 클릭 지점 | 열리는 화면 | 닫거나 돌아갈 때 |
|---|---|---|
| 비행기 보관함 | 휴대품/상자·이동·세척·폐기 모달 | 야영지 보관함 지점 |
| 휴식 공간 | 상태·휴식 시간·회복 예상 모달 | 야영지 휴식 지점 |
| 치료 공간 | 상태·의료 키트·치료 예상 모달 | 야영지 치료 지점 |
| 비행기 정비 | 색상 항공기 상면도 전체 화면 | 야영지 정비 지점 |
| 야영지의 메인으로 돌아가기 | 메인 | 메인 안전지대 버튼 |

처음 안전지대에 들어갈 때 전체 관리표 대신 야영지 배경과4개 공간을 보여준다. 그림 속 물건에 대응하는 이름 있는 버튼을 누른다. 모달 뒤 야영지를 그대로 표시하지만 모달이 열린 동안 배경 버튼은 inert로 조작할 수 없다.

## 비행기 정비

흰색/청색 개인 비행기의 상면도에 이번 판에서 고장난4개 부품만 표시한다. 표시 위치는 partId별로 고정하고 조합 배열 순서와 무관하다. 비행기 모양과 위치는 게임 설명용 도식이다.

- ⚒: 미수리. 클릭하면 부품명·필요 재료/세척 재료 보유량·수리 시간·제한 이유가 우측에 나온다.
- ✓: 수리·장착 완료. 색상과 문자로 함께 구분한다.
- 재료가 없어도 아이콘을 눌러 정보를 볼 수 있다. 실제 수리 버튼만 회색으로 제한한다.
- 수리는 기존 REPAIR_PART, 탈출은 ESCAPE를 사용한다. 모든 부품을 수리해도 직접 탈출하기를 눌러야 한다.
- 낮은 화면에서는 우측 상세 영역 안에서 스크롤할 수 있다. 도안과 HUD는 그대로 유지된다.

## 데이터와 시간

공간 진입은 GET screen으로 최신 상태만 읽고 체력·시간·재료를 변경하지 않는다. 야영지 하위 창 닫기와 정비 돌아가기는 조회 없이 로컬 이동이므로 오프라인·미확정 요청 중에도 복귀할 수 있다. pending 변경은 취소되지 않으며 전역 다시 시도로 확인한다. 오래된 응답이 닫은 창을 다시 열지 않는다.

기존 POST/PATCH/DELETE와 게임 규칙은 유지한다. 재료 묶음 이동·세척·폐기/휴식/치료는 [기존 학습 가이드](Scrap_Escape_안전지대_학습가이드.md)의 API·CRUD 설명을 따른다. 독립 /dev/safe-zone.html에서는 이전 전체 관리 보기를 유지하여 기능만 따로 검증할 수 있다.

- MySQL115개·JavaScript61개·JAR 빌드 성공.
- 야영지4개 지점, 영역별 모달, 정비 전체 화면, 메인/야영지 복귀 및 해당 지점 포커스 확인.
-1280×720·1440×900·1920×1080에서 야영지 버튼/HUD·도안 아이콘/상세 영역 겹침·화면 잘림·바깥 스크롤 없음 확인.
- 실제 별도 서버18080·scrap_escape_test에서 휴식·상자 이동·세척·질병 치료·도안의4개 수리·탈출 성공 확인. 수리용 재료와 질병은 기록한 테스트 판에 준비한 조건이며 자연 탐색 난이도 실측은 아니다.
- 하위 창 X/Escape가 야영지로, 야영지 Back이 메인으로 복귀함을 확인. 이동/정보 열람만으로 변경 API 없음.
- 오프라인에서도 하위 창 닫기 가능. 기존 탐색 전체 화면/보상과 최종 결과 흐름 회귀 확인.
- 새 부품 위치·허용하지 않는 area·미확정 요청 중 닫기·오프라인 닫기 테스트 포함. 콘솔 미처리 예외0.

실제 비행기 부위별 파손 애니메이션·탈출 비행 연출은 추가하지 않았다. 기존 확률·수리 조합·게임 난이도 변경도 없다. 자연 탐색 플레이 밸런스는 별도 검증이 필요하다.
