# 도시 건물 선택·넓은 창 배치

## 탐색 흐름

메인 → 탐색 지역 → 오염 도시의 건물 선택 → **지역 정보 창 → 선택하기** → 보상 확인 → 메인 또는 새 비밀의 방 선택.

도시의 고물상·전자제품 매장·마트·정비소·통신 시설·병원을 배경 속 위치에 맞는 버튼으로 표시한다. 건물을 누르는 것은 탐색 실행이 아니다. 정보 창에는 지역 설명·큰 사진·재료 후보·지역별 보급품과 선택하기를 표시한다. 공통 시간·체력·오염·확률은 도시 화면의 인벤토리 위에 같은 폭의 작은 설명 패널로 표시하고 수색 창에서는 중복하지 않는다. 선택하기로 실행한다. 체력이 부족해도 정보는 볼 수 있고 실행만 회색으로 제한한다.

X/Escape로 정보 창을 닫으면 도시의 해당 건물로 복귀한다. 도시의 돌아가기는 메인으로 간다. 기억한 방은 ?로 표시하고 별도 방 선택 흐름을 유지한다.

## 창 배치 변경

- 모달 뒤 배경을 어둡고 흐리게 처리하며 새 게임·배경 지점을 포함해 조작을 막는다.
- HUD 공간을 피하던 고정 높이를 없애고 창을 크게 배치한다. 내용이 적은 휴식/치료는 콘텐츠 높이에 맞춘다.
- 보관함은 왼쪽 휴대품, 가운데16칸 상자, 오른쪽 선택 재료/이동/세척/폐기 확인으로 나눈다.
- 최종 결과는6열 통계로 바꿔 기본 해상도에서 모두 표시한다.
- 공통 메시지와 다시 시도는 창 아래 footer 안에 표시한다. 창 밖 배경을 클릭할 필요가 없다.
- 정비 도안은 오른쪽 상세 창을 향해 붙이고 간격을16px로 맞춘다. 상세 폭을 늘리고 재료를2열로 표시해 불필요한 스크롤을 줄인다.

## 데이터 처리

새 HTTP API나 게임 규칙은 없다. 정보 진입은 GET screen, 실행은 기존 EXPLORE/POST explorations, 성공 후 GET screen 갱신이다. 도시 복귀/창 닫기는 로컬 처리이며 서버 응답이 없어도 나갈 수 있다. 응답 유실은 기존 요청 번호로 재시도하고 행동을 중복 적용하지 않는다.

## 검증 — 2026-10-27

- Java/MySQL115개·JavaScript63개, JAR 빌드 통과.
-1280×720·1440×900·1920×1080: 가득 찬4칸/16칸과 폐기 확인 상태, 휴식, 치료, 도시 정보 창, 최종21개 결과 통계에서 일반 내부 스크롤 없음 확인.
- 정비 상세의 내부 스크롤0, 도안과 상세 간격16px 확인. 화면 크기·배경 입력 차단·불필요한 창 높이·화면 밖 버튼도 검사했다.
- 건물6개 버튼과 HUD의 겹침·바깥 스크롤 없음, 정보 진입 시 탐색 POST 없음, 선택하기 후 실제 병원 탐색1회·키트1개 획득 확인.
- 체력0에서도 지역 정보 열기 가능하고 선택만 차단됨 확인.
- 서버에서 성공했지만 탐색 응답만 유실시킨 뒤 창 내부 다시 시도로 동일 행동을 확인했다. 중복 탐색 시간 소모 없음.
- 결과 창의 새 게임은 시작 화면으로 로컬 복귀하며 배경 inert를 해제함 확인. 콘솔 미처리 예외0.

길이가 큰 예외 메시지나 확대 글꼴에서는 접근성을 위해 내부 overflow를 허용한다. 자연 탐색으로 탈출하는 난이도·외부 배포 검증은 이번 변경에 포함하지 않는다. 이번 변경은 자동 커밋/푸시하지 않았다.

## 탐색 안내·수색 사진 배치 조정 — 2026-10-27

- 상단 가로 안내 바를 없애고 인벤토리 위400px 설명 패널로 옮겼다. 인벤토리 높이가 변해도 위쪽에 함께 배치되며 입력란/테두리 대신 작은 제목·본문·말풍선 꼬리 형태를 사용한다.
- main.mjs가 기존 explorationSharedInfo로 공통 수치를 읽으므로 낮/밤·질병·폭풍 값은 동일하다. 탐색 화면을 떠나면 안내를 숨긴다.
- 수색 창의 공통 비용/확률 문구는 제거하고 사진·지역 설명·선택하기 영역을 확대했다. 수색 창 폭은1120px까지, 사진 기본310px/낮은 화면260px, 버튼54px 이상이다.
- 기한 초과 경고와 체력/인벤토리 부족 이유는 유지한다. 낮은 화면에서는 병원 지점을 조금 위로 옮겨 설명 패널과 겹치지 않게 했다.
- JS63개·빌드 통과. Chrome1280×720·1440×900·1920×1080에서 가득 찬 인벤토리와 질병 기한 경고까지 패널 폭/좌우 정렬·10px 간격·건물 겹침 없음·수색 창 무스크롤·공통 문구 없음·사진/버튼 확대·메인 복귀 후 숨김을 확인했다. 백엔드/API는 변경하지 않았다.
