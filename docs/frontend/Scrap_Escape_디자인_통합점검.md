# 디자인 통합 점검

적용: 재료/보급품 SVG13종, 장소별 PNG6종, 비밀의 방 문, 성공/실패 엔딩, 안전지대 작업 패널 및 공통 버튼/HUD 마감. 기존 API·비용·확률은 유지한다.

실제 Chrome에서1280×720/1440×900/1920×1080의 보관함·휴식·치료·비밀의 방·성공·실패18개 조합을 렌더링했다. 보관함은 휴대4/상자16칸이 찬 상태로 점검했다. 각 창의 화면 내 배치와 내부 스크롤 없음, JS예외0을 확인했다. 별도 테스트 화면에서 실제 제품 View/CSS를 사용한 결과이며 긴 예외 문구나 모든 선택 조합을 보장하지는 않는다.

별도18080/scrap_escape_test의 실제 앱에서 세척액 부족 차단, 다중 세척/폐기·휴식·정비·탐색 결과 복귀 동작도 확인했다. 장소6/문1/엔딩2 이미지 HTTP200. JavaScript74개 통과, bootJar 성공. 점검 중 성공 배너의 비행기 잘림을 background-position으로 조정하고 보관함의 중복 안내를 제거했다.
