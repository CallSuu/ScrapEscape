게임명: Scrap Escape

## 1. 프로젝트 개요

비행 중 부품 파손으로 방사능에 오염된 폐도시에 비상착륙한 플레이어가 주변을 탐색하고, 고철을 세척·조합해 비행기를 수리한 뒤 탈출하는 게임이다.

기본 배경과 버튼 중심 화면으로 구현한다. 시작 후 10일 안에 부품 7종 중 무작위로 지정된 고장 부품 4개를 모두 수리하면 성공한다. 로그인과 이어하기는 제공하지 않는다. 플레이 중 데이터는 DB에 저장·조회·수정·삭제하며 한 판이 끝나면 결과 통계를 보여준다.

밤 탐색, 연속 탐색에 따른 오염과 질병, 방사능 폭풍을 통해 탐색 시점과 자원 사용을 고민하게 한다. 비밀의 열쇠와 장소별 비밀의 방은 MVP 완성과 플레이 검증 후 시간이 남으면 추가한다.

수업 목표는 재료 획득, 보관 위치 이동, 상태 변경, 재료 소비와 폐기를 통해 CRUD와 데이터 관계를 명확하게 시연하는 것이다.

## 2. 구현 범위 — MVP와 선택 확장

- 고정된 안전지대 배경, 통합 탐색 버튼과 장소 선택 카드
- 탐색 장소 6곳, 일반·특수 재료 총 10종, 고정 조합법 7개
- 인벤토리 4칸, 비행기 보관함 16칸
- 체력, 행동 기반 게임 시간, 낮·밤, 세척액 및 의료 키트
- 재료 세척, 보관, 48시간 경과에 따른 사용 불가, 폐기
- 플레이어 오염도, 연속 탐색, 질병, 병원과 치료
- 24\~48시간 간격의 방사능 폭풍
- 무작위 고장 부품 4개 수리, 10일 제한, 성공·실패 엔딩과 통계
- 모든 선택창의 상태 정보, 실행 제한 이유, 비활성 버튼과 X 버튼

지도 이동, 전투, 판매, 로그인, 이어하기, 실제 시간 타이머는 범위에서 제외한다. 5개 부품 수리 난이도와 첫 방문 보급 상자·임시 정비 등 추가 이벤트는 추후 검토 대상으로 두며 현재 기본 범위에 포함하지 않는다.

### MVP 이후 선택 확장

비밀의 열쇠 획득, 장소별 비밀의 방 발견·기억·선택 입장·재방문, 방 보상·손실, 관련 DB 처리와 엔딩 통계는 MVP 외 기능이다. 기본 게임 완성·화면 연동·플레이 검증을 먼저 마치고 시간이 남으면 구현한다. 상세 기획은 8.3항에 보존한다.

## 3. 한 판의 시작과 종료

| 항목 | 초기 설정 |
| --- | --- |
| 시간 | 1일 차 08:00, 경과 시간 0시간 |
| 제한 시간 | 시작 후 240시간, 즉 10일 |
| 체력 | 15/15 |
| 세척액 | 1/10회분 |
| 의료 키트 | 0/2개, 재료 슬롯과 별도 관리 |
| 오염도·질병 | 오염도 0/100, 질병 없음, 연속 탐색 0회 |
| 인벤토리·보관함 | 4칸·16칸, 비어 있음 |
| 고장 부품 | 7종 중 중복 없이 무작위 4개 |

경과 시간이 240시간 미만인 상태에서 수리 대상 4개를 모두 수리한 뒤 탈출 버튼을 누르면 성공한다. 240시간 이상이면 장기 오염 노출 한계에 도달해 실패한다. 마지막 수리와 제한 시간 도달이 동시에 발생하면 실패로 처리한다.

오염도 100이나 발병 자체는 즉시 실패가 아니다. 다만 질병 발생 후 72시간(3일) 안에 치료하지 않으면 실패한다. 체력 0에서도 휴식할 수 있다. 행동 완료 시 생존 제한과 질병 기한을 검사하며, 동시에 초과한 경우 현재 구현은 생존 시간 초과(TIME_LIMIT)를 우선 표시한다.

10일은 확장 기획의 초기 제한 시간이며 실제 탈출 가능성과 플레이 길이는 구현 후 검증한다.

## 4. 기본 진행 흐름

1. 고장 부품과 조합법, 다음 방사능 폭풍 일정을 확인한다.
2. 안전지대에서 인벤토리를 보관함에 정리한다.
3. 통합 탐색 버튼을 눌러 장소 선택 창을 연다.
4. 장소별 보상, 시간, 체력, 예상 오염 증가를 비교하고 탐색한다.
5. 재료·보급품 획득, 시간·체력·오염도·질병 판정을 반영한다.
6. 선택 확장 구현 시 비밀의 방을 발견하면 기억하고, 열쇠가 있어도 입장 여부를 직접 선택한다.
7. 재료를 보관·세척·폐기하고 필요하면 휴식하거나 의료 키트를 사용한다.
8. 필요한 재료를 모아 부품을 제작하고 즉시 비행기에 장착한다.
9. 수리 완료 또는 240시간 도달까지 반복한다.

탐색은 버튼 행동으로 출발·수색·귀환을 처리한다. 선택 확장의 방은 즉시 입장하거나 위치만 기억해 나중에 방문할 수 있다. 발견한 방을 열지 않아도 다음 탐색은 가능하다. 종료된 게임에서는 새 행동을 실행하지 않는다.

## 5. 행동과 시간

실제 시간이 흘러도 게임 시간은 변하지 않는다. 유효한 행동을 완료할 때만 시간이 진행한다.

| 행동 | 소요 시간 | 체력 변화 |
| --- | --- | --- |
| 일반 낮 탐색 | 6시간 | −2 |
| 일반 밤 탐색 | 7시간 | −3 |
| 질병 중 낮 탐색 | 8시간 | −4 |
| 질병 중 밤 탐색 | 9시간 | −5 |
| 재료 한 묶음 세척 | 1시간 | 없음 |
| 부품 제작·즉시 장착 | 3시간 | 없음 |
| 휴식 | 선택한 1\~8시간 | 시간만큼 회복, 6시간 이상이면 추가 2 |
| 의료 키트 사용 | 1시간 | 없음 |
| 비밀의 방 발견 직후 입장 — 선택 확장 | 1시간 | −1 |
| 이동·폐기·조회·창 닫기·방 지나치기 | 없음 | 없음 |

체력은 최대 15이며 부족하면 해당 행동만 제한한다. 질병이 있어도 필요한 체력이 충분하면 탐색할 수 있다.

밤은 20:00 이상부터 다음 날 06:00 미만까지다. 탐색 출발 시각으로 낮·밤 시간·체력·보상 기준을 정하며 도중에 변경하지 않는다. 질병은 출발 시 상태에 따라 탐색 시간과 체력 비용에 각각 +2를 적용한다.

방사능 폭풍은 출발 시각이 아니라 실제 행동 구간과 겹친 시간으로 계산한다. 날짜는 자정을 지날 때 증가하며 탈출 제한은 경과 시간으로 판정한다.

선택 확장의 기억한 방 재방문은 정상 낮 4시간·체력 2, 정상 밤 5시간·체력 3, 질병 중 낮 6시간·체력 4, 질병 중 밤 7시간·체력 5다. 이동·개방을 포함한 비용이며 추가 1시간을 더하지 않는다.

## 6. 탐색 장소와 결과

메인 화면에는 탐색 버튼 하나를 배치한다. 장소를 각각 카드로 구분한 선택 창에서 상세 정보를 보고, 공통 탐색 시작 버튼을 눌러 실행한다.

| 장소 | 획득 후보 | 역할 |
| --- | --- | --- |
| 고물상 | 철 조각, 기어, 고무 부품 | 기계 부품 |
| 전자제품 매장 | 구리 전선, 회로 기판, 배터리 셀 | 전기·전자 부품 |
| 마트 | 플라스틱 부품, 고무 부품, 필터 | 생활·여과 재료 |
| 정비소 | 철 조각, 기어, 내열 합금 | 엔진·기체 재료 |
| 통신 시설 | 구리 전선, 회로 기판, 신호 모듈 | 통신·항법 재료 |
| 병원 | 의료 키트 확정 1개, 필터·플라스틱 부품 확률 획득 | 치료·보조 재료 |

기존 일반 재료 6종에 배터리 셀·필터·내열 합금·신호 모듈을 더해 총 10종으로 구성한다. 의료 키트와 세척액은 별도 보급품이다.

일반 재료는 탐색당 최대 두 종류, 총수량은 낮 0\~3개·밤 0\~4개로 정한다. 0개는 탐색 실패가 아니라 빈손으로 정상 귀환한 결과다. 병원은 일반 재료가 0개여도 의료 키트 1개를 지급한다.

| 총 재료 수량 | 낮 확률 | 밤 확률 |
| --- | --- | --- |
| 0개 | 5% | 5% |
| 1개 | 15% | 0% |
| 2개 | 35% | 20% |
| 3개 | 45% | 35% |
| 4개 | 0% | 40% |

총수량 판정 후 첫 재료를 장소 후보에서 균등 선택한다. 총수량이 2개 이상이면 첫 재료를 제외한 후보에서 두 번째 재료를 균등 선택한다. 첫 재료 수량은 1부터 총수량−1까지 균등 선택하고 나머지를 두 번째 재료에 배분한다. 공간이 한 칸뿐이면 첫 재료 묶음부터 보관하며 초과분은 두고 온다.

모든 일반 탐색에서 세척액을 발견하며, 지급량은 70% 확률로 1회분·30% 확률로 2회분이다. 재료 0개 결과와도 독립적이다. 최대10회분까지만 저장하고 넘치는 양은 저장하지 않는다. 병원에도 같은 규칙을 적용한다.

장소 카드에는 후보 재료·보급품, 수량 범위, 시간, 체력, 기본·연속 탐색·폭풍을 합한 예상 오염 증가를 표시한다. 다음 폭풍 일정과 질병 비용도 확인할 수 있다.

인벤토리가 가득 차면 탐색을 시작할 수 없다. 빈칸이 일부만 있는 경우 획득 가능한 묶음까지만 보관하고 초과 재료는 현장에 두고 오는 초기안으로 정리한다. 획득되지 않은 수량을 결과에 안내하며 종류 선택 우선순위는 구현 시 명시한다.

창 열기·장소 선택·취소는 비용이 없다. 실행 시 서버가 조건을 다시 검증한다.

빈손 메시지 예시: “구석까지 뒤졌지만 쓸 만한 부품은 없었다.”

## 7. 인벤토리와 보관함

인벤토리는 4칸, 비행기 보관함은 16칸을 초기값으로 정한다. 슬롯 하나에는 같은 탐색에서 얻은 같은 종류의 재료 묶음을 넣는다. 철 조각 3개는 한 칸을 사용하며 최대 두 종류를 얻으면 최대 두 칸을 사용한다.

미세척 재료는 종류가 같아도 획득 시점이 다르면 별도 묶음으로 보관한다. 보관 위치를 옮겨도 획득 시각과 만료 시각은 변하지 않는다.

모든 재료 묶음은 미세척·세척 완료·사용 불가 상태에 관계없이 최대 6개까지 보관한다. 미세척 재료는 획득 시각이 다르면 합치지 않는다. 세척된 같은 종류 재료는 같은 보관 위치에서 6개까지 자동으로 합치고 초과분은 다른 칸에 보관한다. 예를 들어 4개와 4개는 6개·2개로 두 칸을 사용한다. 이동할 공간이 부족하면 전체 이동을 막고 이유를 표시한다. 수리에는 여러 세척 묶음의 수량을 합산해 사용한다.

보관함 정리는 안전지대에서 다음 탐색 전에 가능하며 탐색 도중에는 접근할 수 없다. 이동 대상 공간이 부족하면 실행을 막고 이유를 표시한다. 탐색 준비물은 요구하지 않는다.

제작에는 인벤토리와 보관함의 세척 재료를 함께 사용한다. 세척액과 의료 키트는 재료 슬롯을 차지하지 않는다.

## 8. 오염과 세척

획득한 재료는 모두 세척 전 상태이며, 비행기 부품 제작에 사용할 수 없다. 획득 시각은 탐색 완료 시각으로 기록한다.

재료 상태는 다음 세 가지다.

| 상태 | 제작 가능 | 설명 |
| --- | --- | --- |
| 세척 전 | 불가 | 획득 후 48시간 이내 세척 가능 |
| 세척 완료 | 가능 | 시간 경과로 사용 불가가 되지 않음 |
| 사용 불가 | 불가 | 세척하지 않고 48시간 이상 방치한 재료 |

행동 후 시간이 진행될 때 세척 전 재료의 만료 여부를 확인한다. 사용 불가 재료는 자동 삭제하지 않고 슬롯을 계속 차지한다. 플레이어가 직접 폐기해 공간을 확보한다. 사용 불가 상태가 된 재료는 세척으로 복구할 수 없다.

세척은 선택한 묶음 전체에 적용하되, 재료 1개당 세척액 1회분을 사용한다. 예: 철 조각3개 묶음은 세척액3회분·시간1h, 두 묶음의 수량이2개+3개이면 액5회분·시간2h다. 체력 소모는 없으며 양쪽 저장소에서 여러 묶음을 함께 선택할 수 있다. 전체 필요량보다 세척액이 적으면 버튼을 비활성화하고 부족량을 안내한다. 서버도 전체 요청을 취소해 일부만 세척되지 않도록 한다. 폐기 역시 다중 선택·전체 목록 확인 후 한 번에 처리한다.

세척 시작 시점에 재료가 사용 가능하면 세척으로 보호된다고 판정한다. 따라서 세척 중 48시간 기준을 넘더라도 해당 재료는 세척 완료 상태가 된다.

세척액은 별도 통 게이지로 관리하며 슬롯을 차지하지 않는다. 시작1회분·최대10회분이다. 일반 탐색마다 1회분70%/2회분30%로 지급하며, 재료가0개여도 지급한다. 보유9일 때2회분을 발견해도1회분만 저장한다. 비밀의 방 보급 결과의 세척액은 별도 규칙으로2회분을 지급하되 같은 상한을 적용한다.

### 8.1. 플레이어 오염도와 질병

재료의 48시간 만료와 플레이어 오염도는 별도로 관리한다. 오염도는 0\~100이며 시작 시 0이다. 일반 탐색은 기본 +10, 연속 탐색 3회째부터 추가 +5를 적용한다.

휴식은 1시간당 오염도를5 낮춘다(2h−10,4h−20,6h−30,8h−40, 최소0). 한 번에4시간 이상 휴식하면 연속 탐색 횟수도 초기화한다. 1~3시간 휴식은 오염도만 낮추며 횟수는 유지한다. 휴식은 질병을 치료하거나 치료 기한을 초기화하지 않는다.

탐색 종료 시 오염 증가를 반영한 뒤 발병을 판정한다. 선택 확장의 비밀의 방 종료에도 판정한다. 이미 질병이 있으면 재발병·중첩·치료 기한 갱신은 없다.

| 오염도 | 발병 확률 |
| --- | --- |
| 0\~59 | 0% |
| 60\~79 | 30% |
| 80\~89 | 40% |
| 90\~100 | 60% |

90을 중복 구간에 포함하지 않도록 80\~89와 90\~100으로 구분한다. 오염도 100에서도 확정 발병은 아니며 60%를 적용한다.

질병은 탐색 금지가 아니라 탐색 시간 +2시간·체력 소모 +2의 불이익이다. 발병 시각부터 72시간(3일) 동안 방치하면 실패한다. 실제 시간이 아닌 게임 경과 시간이며 휴식으로 기한이 초기화되지 않는다.

의료 키트를 사용하면 질병을 제거하고 오염도 60을 낮춘다. 오염도는 최소 0이며 100에서 사용하면 40이 된다. 치료 직후에는 발병을 판정하지 않고 탐색·비밀의 방 종료 시에만 판정한다. 키트는 별도 최대 2개 보유하며 병원에서 확정 1개를 얻는다. 사용 시간은 1시간, 체력 소모는 없다. 치료 완료가 발병 후 72시간에 도달하기 전에 끝나야 하며 정확히 도달하거나 넘으면 실패한다. 기한을 넘는 치료로 실패를 취소하지 않는다.

모든 행동창에 질병 여부와 치료까지 남은 시간을 표시한다. 72시간 미치료 실패 또는 240시간 생존 제한 실패를 수리 성공보다 우선 판정한다.

### 8.2. 방사능 폭풍

시간대별로 고정된 오염 위험 수준을 두지 않는다. 밤의 추가 시간·체력 소모는 어둠과 위험 요소를 표현하고, 폭풍은 별도 오염 변수로 사용한다.

폭풍은 경과24~48시간 중 균등 선택한 시각에 처음 발생하며, 이후 시작 시각 사이 간격도24~48시간 중 균등 선택한다(각 정수4%). 지속 시간은1/2/3시간 각각1/3이다. 겹치지 않으며 다음 폭풍 시각을 표시한다.

탐색 또는 비밀의 방 체류 시간이 폭풍과 겹치면 겹친 시간당 오염도 +5를 적용한다. 여러 폭풍과 겹치면 각각 합산한다. 안전지대의 휴식·세척·수리·치료에는 폭풍 오염이 없다.

예: 6시간 탐색 중 2시간 폭풍에 노출되면 기본 +10과 폭풍 +10으로 총 +20이다. 연속 탐색 보정은 별도로 더하며 최종 오염도는 100을 넘지 않는다.

시간은 행동으로만 진행하고 실제 타이머나 백그라운드 작업은 사용하지 않는다.

### 8.3. 비밀의 열쇠와 비밀의 방 — MVP 외 선택 확장

MVP를 완성하고 플레이 검증을 마친 뒤 시간이 남을 경우 구현한다. 이 기능 없이도 기본 게임을 완료할 수 있어야 한다.

각 탐색지에는 비밀의 방이 하나씩 존재한다. 장소 6곳에 총 6개이며 방마다 한 번만 개방할 수 있다.

### 열쇠 획득과 방 발견

- 모든 일반 장소 탐색에서 10% 확률로 비밀의 열쇠 1개를 얻는다. 빈손 탐색에서도 가능하며 방 발견과 독립적으로 판정한다.
- 열쇠는 재료 슬롯과 별도로 최대 2개 보유한다. 한도 초과분은 저장하지 않고 결과에 안내한다.
- 아직 발견하지 않은 해당 장소의 방은 일반 탐색 완료 후 15% 확률로 발견한다. 게임 종료 시 새 발견은 처리하지 않는다.
- 발견 시 해당 장소의 위치를 기억한다. 열쇠가 있어도 자동으로 사용하지 않으며 입장 여부를 직접 선택한다.
- 발견 직후 입장은 열쇠 1개·1시간·체력 1을 소비한다. 질병의 탐색 비용 보정은 이 즉시 입장에 추가하지 않는다.
- 열쇠가 없거나 체력이 부족하면 실행 버튼은 회색으로 비활성화하고 이유를 표시한다. 정보는 확인할 수 있다.
- 지나치거나 X로 닫으면 위치만 기억한다. 다음 탐색을 막지 않는다. 열쇠는 실제 입장할 때만 소비한다.

### 기억한 방 재방문

탐색 장소 선택창에서 미발견 장소에는 버튼이 없고, 발견한 장소에만 별도 “?” 버튼을 표시한다. 모든 방을 발견하면 여섯 장소 모두 선택지가 나타난다.

| 상태 | 낮 방문 | 밤 방문 |
| --- | --- | --- |
| 정상 | 4시간·체력 2 | 5시간·체력 3 |
| 질병 | 6시간·체력 4 | 7시간·체력 5 |

아는 길이므로 일반 탐색보다 2시간 짧다. 비용은 이동·개방을 모두 포함하며 추가 개방 시간을 더하지 않는다. 출발 시각과 질병 상태로 비용을 정한다.

재방문은 일반 탐색과 같은 기본 오염 +10·연속 탐색 보정·폭풍 노출을 적용한다. 재방문도 연속 탐색 횟수에 포함한다. 방 보상만 지급하며 일반 탐색 재료·세척액·열쇠 획득 판정을 중복 지급하지 않는다.

“?” 버튼은 방문 정보창을 여는 용도다. 열쇠·체력이 부족해도 정보창은 열 수 있으며 시간·체력·필요 열쇠·보상·위험을 확인한 뒤 별도의 입장 버튼으로 실행한다. 실행 불가 입장 버튼만 회색으로 비활성화하고 이유를 표시한다. 개방 완료한 방은 “탐색 완료”로 표시하며 재입장을 막는다. 조건은 화면과 서버 양쪽에서 확인한다.

### 방 결과

| 결과 | 전체 확률 | 효과 |
| --- | --- | --- |
| 좋음 | 50% | 해당 장소 후보 재료 3\~4개 추가 |
| 좋음 | 30% | 세척액 2회분 또는 의료 키트 1개 |
| 나쁨 | 10% | 입장 당시 인벤토리의 미세척 재료 1\~2개 손실 |
| 나쁨 | 10% | 오염도 추가 +15 |

좋은 결과80%, 나쁜 결과20%다. 보급30%는 세척액2회분15%·키트1개15%로 나뉜다. 손실10%는 입장 시 휴대 인벤토리에 미세척 재료가 없으면 오염+15로 대체해, 이 경우 오염 결과가20%가 된다. 손실량은1/2개 각각50%로 추첨한 뒤 가진 수량까지만 적용한다. 시작 묶음을 균등 선택하고 부족하면 다음 묶음으로 이어서 차감한다.

손실은 보관함·세척 완료 재료에 적용하지 않으며 인벤토리에 남은 미세척 수량을 넘지 않는다. 대상이 없으면 오염도 증가 결과로 대체한다. 입장 전에 손실 가능성을 안내한다.

추가 재료는 입장 완료 시각을 획득 시각으로 기록한 미세척 묶음으로 보관하며 기존 묶음의 만료를 연장하지 않는다. 공간이나 보급품 한도 초과분은 보관하지 않고 결과에 안내한다.

실제 즉시 입장 또는 재방문 구간의 폭풍 오염을 계산하며 나쁜 결과 +15는 별도로 더한다. 종료 시 발병·재료 만료·질병 기한·10일 제한을 판정한다.

무작위 결과는 서버에서 정하며 개방·열쇠 소비·보상·손실·통계를 한 번만 처리한다. 확률과 수량은 플레이 검증 전 초안이다.

## 9. 고장 부품과 고정 조합법

| 부품 | 필요 재료 | 합계 |
| --- | --- | --- |
| 엔진 시동 장치 | 철 조각 2 + 기어 2 + 구리 전선 2 + 배터리 셀 1 | 7 |
| 동력 전달 장치 | 철 조각 2 + 기어 3 + 고무 부품 2 | 7 |
| 연료 공급 장치 | 철 조각 1 + 고무 부품 3 + 플라스틱 부품 2 + 필터 1 | 7 |
| 냉각 장치 | 구리 전선 1 + 고무 부품 2 + 플라스틱 부품 2 + 내열 합금 2 | 7 |
| 비행 제어 장치 | 회로 기판 2 + 구리 전선 2 + 플라스틱 부품 2 + 신호 모듈 1 | 7 |
| 통신·항법 장치 | 회로 기판 2 + 구리 전선 2 + 배터리 셀 2 + 신호 모듈 1 | 7 |
| 기체 보강 장치 | 철 조각 2 + 내열 합금 3 + 고무 부품 2 | 7 |

시작 때 중복 없이 선택한 4개만 수리 대상으로 표시한다. 필요한 총 재료는 32\~33개이며 선택되지 않은 부품은 정상이다. 5개 수리는 플레이 검증 후 별도 난이도로 검토한다.

세척 재료가 충분하면 소비 후 3시간을 진행하고 즉시 수리·장착한다. 완성품은 인벤토리에 넣지 않으며 이미 수리한 부품은 다시 제작할 수 없다. 조합법은 고정이고 재료 수량은 밸런스 초안이다.

## 10. 화면 구성

- 상단: 날짜·시각, 남은 시간, 체력, 오염도, 질병·치료 기한, 세척액, 의료 키트, 현재·다음 폭풍 정보
- 중앙: 비행기와 안전지대 배경, 수리 대상 4개 진행 상태
- 탐색: 통합 버튼과 6개 장소 카드, 예상 보상과 시간·체력·오염 비용
- 재료: 인벤토리 4칸·보관함 16칸, 이동·세척·폐기
- 제작: 필요 수량·세척 재료 보유 수량·제작 버튼
- 휴식·치료: 휴식 시간·예상 회복량·오염 감소, 의료 키트 효과
- 결과: 탐색·세척·수리 결과와 비밀의 방 발견·결과 메시지

각 재료에는 종류·수량·상태를 표시한다. 미세척 재료 아이콘 위에는 “사용 불가까지 18시간”처럼 묶음별 남은 시간을 표시한다. 12시간 이하이면 주황색, 6시간 이하이면 빨간색으로 강조한다. 획득 후 48시간이 지나면 “사용 불가” 표시와 어두운 아이콘으로 바꾸고, 세척 완료 재료에는 남은 시간 대신 깨끗한 상태 표시를 제공한다. 시간 표시는 행동으로 게임 시간이 진행될 때만 갱신하며 보관 이동으로 변경되지 않는다.

모든 탐색·행동·선택 창에서 날짜·시각, 체력, 오염도, 질병, 세척액, 의료 키트를 항상 확인할 수 있게 한다. 실행할 수 없는 버튼은 회색으로 비활성화하고 “체력 부족: 필요 5 / 현재 3”처럼 이유를 표시한다. 장소 상세 정보는 실행 불가 상태에서도 열람할 수 있다.

모든 팝업·선택창에 우측 상단 X 버튼을 제공한다. 실행 전 창 닫기는 취소이고 비용이 없다. 실행이 끝난 결과창을 닫아도 자원과 시간은 되돌아가지 않는다.

선택 확장 구현 시 열쇠 수량을 표시하고, 장소 카드에 발견한 방의 “?” 버튼을 추가한다. X로 닫으면 발견 상태를 유지하며 다음 탐색은 허용한다. 발견 직후 입장 기회를 넘긴 뒤에는 기억한 방 재방문 비용을 적용한다. 개방 완료한 방에는 완료 표시를 제공한다.

## 11. 엔딩과 통계

성공: 240시간 미만에 모든 고장 부품 4개를 수리하고 탈출한다.

실패: 시작 후 240시간 이상 경과하거나 질병을 발병 후 72시간 동안 치료하지 않는다. 결과에 실패 원인을 구분해 표시한다.

성공·실패 모두 아래 통계를 표시한다.

- 결과와 총 경과 시간, 수리 부품 수 0\~4개
- 전체·낮·밤·빈손 탐색 횟수
- 획득·세척·폐기한 개별 재료 수량
- 남은 체력, 최종·최대 오염도
- 질병 발생·치료 횟수, 의료 키트 사용 횟수
- 폭풍 노출 시간

### 선택 확장 구현 시 추가 통계

- 비밀의 방 발견 수·개방 수: 각각 0\~6개
- 발견했지만 열지 않은 방 수
- 비밀의 열쇠 총 획득 수·사용 수·남은 수
- 방의 좋은·나쁜 결과 횟수
- 방 추가 획득량과 손실 재료 수량

열쇠 총 획득 수는 실제 보관한 개수로 집계한다. 보유 한도 때문에 놓친 열쇠는 별도로 안내하며 획득 수에 포함하지 않는다.

재료 수량은 슬롯 수가 아니라 개별 수량이다. 방에서 잃은 재료는 직접 폐기와 구분해 집계한다. 초과 용량 때문에 가져오지 못한 재료는 보유 재료 획득량과 구분해 결과에 안내한다.

엔딩에 다시 시작 버튼을 제공한다.

## 12. DB 설계 방향

로그인과 이어하기가 없어도 플레이 중 상태는 DB에 저장한다. 각 판에 게임 ID를 발급하고 해당 판의 데이터를 구분한다. 새로고침 후에는 새 판을 시작하는 기본안으로 잡으며, 이전 판을 이어서 불러오지 않는다. 게임 종료 후 결과 화면에 필요한 데이터는 남겨두고, 이전 판 정리 정책은 구현 환경에서 결정한다.

| 데이터 | 핵심 내용 |
| --- | --- |
| 게임 상태 | 게임 ID, 경과 시간, 체력, 세척액, 의료 키트, 오염도, 질병, 연속 탐색, 결과 상태, 통계 |
| 재료 종류 | 이름, 탐색 장소 |
| 보유 재료 묶음 | 게임 ID, 재료 종류, 수량, 보관 위치, 획득 시각, 세척·사용 불가 상태 |
| 부품 종류 | 부품 이름 |
| 조합 재료 | 부품 ID, 재료 ID, 필요 수량 |
| 게임별 수리 상태 | 게임 ID, 고장 부품 ID, 수리 완료 여부 |

위 구성은 기존 구현을 확장하는 논리 설계이며, 추가 테이블·컬럼은 현재 코드와 마이그레이션 방식에 맞춰 정한다. 재료·부품·조합법은 고정 데이터이고 게임 상태·보유 재료·수리 상태는 판마다 달라지는 데이터다.

### CRUD 시연

| 구분 | 게임 행동 | DB 변화 |
| --- | --- | --- |
| CREATE | 게임 시작, 재료 획득 | 게임·수리 대상·보유 재료 행 생성 |
| READ | 재료와 조합법 확인 | 인벤토리·보관함·필요 재료·수리 상태 조회 |
| UPDATE | 보관 이동, 세척, 휴식, 탐색, 수리 | 위치·상태·체력·시간·수량·수리 여부 변경 |
| DELETE | 폐기, 제작으로 묶음 전량 소비 | 보유 재료 행 삭제 |

묶음 수량은 1\~6개로 유지하고 서버와 DB 제약으로 검증한다. 합치기는 기존 묶음을 최대 6개까지 UPDATE하고 남은 묶음은 유지하며, 전량 흡수한 묶음만 DELETE한다. 새로운 초과 묶음이 필요한 경우 빈칸을 확인한 뒤 INSERT한다. 부분 소비는 수량 UPDATE, 전량 소비는 행 DELETE로 처리한다. 사용 불가 판정은 상태 UPDATE이며 폐기는 실제 DELETE다. 삭제한 재료의 개수는 게임 통계에 누적한다.

부품 제작 시 재료 확인·소비·수리 상태·시간·통계 변경은 하나의 트랜잭션으로 처리해 재료만 사라지거나 중복 수리가 발생하지 않도록 한다. 탐색과 세척도 한 행동의 관련 변경을 함께 반영한다.

### 화면과 DB 사이의 데이터 흐름

플레이어가 버튼을 누르면 화면이 서버에 행동을 요청한다. 서버는 해당 게임의 최신 데이터를 DB에서 조회하고 조건을 확인한 뒤, 필요한 행을 생성·수정·삭제한다. 처리 결과를 저장한 다음 최신 상태를 조회하여 화면에 반환한다. 화면은 반환된 값으로 슬롯·체력·시간·수리 현황을 갱신한다.

```mermaid
flowchart LR
    A[플레이어 버튼 선택] --> B[화면에서 서버로 행동 요청]
    B --> C[DB 조회: 현재 게임과 재료 상태]
    C --> D[서버에서 행동 조건 확인]
    D -->|가능| E[DB에 생성·수정·삭제 반영]
    D -->|불가| F[실행 불가 이유 반환]
    E --> G[최신 상태와 결과 조회]
    G --> H[화면의 슬롯·수치·결과 갱신]
    F --> H
```

서버가 시간·체력·탐색 결과·재료 수량을 결정한다. 화면은 결과를 표시하며 화면의 숫자만 바꾸는 방식으로 게임 상태를 처리하지 않는다. 보관 이동은 같은 보유 재료 행의 위치 값을 바꾸는 UPDATE로 구현한다.

### 행동별 CRUD 처리 순서

| 행동 | 조회(READ) | 저장·수정·삭제 | 화면으로 돌아오는 결과 |
| --- | --- | --- | --- |
| 게임 시작 | 고정 부품·조합법 조회 | 게임 상태와 무작위 수리 대상 4개 INSERT | 초기 체력·시간·수리 목표 |
| 탐색 선택 창 열기 | 장소·재료 정보와 게임 상태 조회 | 변경 없음 | 장소 카드의 예상 보상·비용 |
| 탐색 실행 | 체력·빈 슬롯·시간 확인 | 획득 묶음 INSERT, 체력·시간·세척액·통계 UPDATE | 발견 재료와 최신 상태 |
| 인벤토리·상자 확인 | 위치별 보유 재료 조회 | 변경 없음 | 각 칸의 종류·수량·상태 |
| 상자로 이동 | 대상 묶음과 상자 공간 확인 | 보관 위치 UPDATE | 인벤토리 칸 감소, 상자 칸 증가 |
| 세척 | 재료 상태·체력·세척액 확인 | 세척 상태·체력·세척액·시간·통계 UPDATE | 깨끗해진 재료와 남은 자원 |
| 동일한 세척 재료 합치기 | 같은 위치의 같은 종류 재료 조회 | 남길 묶음 수량 UPDATE, 합쳐진 묶음 DELETE | 합쳐진 수량과 확보된 빈칸 |
| 부품 제작·장착 | 조합법·세척 재료·수리 상태 확인 | 부분 소비 UPDATE, 전량 소비 DELETE, 수리·시간 UPDATE | 소비한 재료와 완료된 부품 |
| 휴식 | 현재 체력·시간 조회 | 체력·시간 UPDATE | 회복 체력과 새 시각 |
| 오래된 재료 상태 판정 | 시간 진행 후 만료 대상 조회 | 해당 묶음을 사용 불가로 UPDATE | 사용할 수 없는 재료 표시 |
| 재료 폐기 | 대상 묶음 확인 | 묶음 DELETE, 폐기 통계 UPDATE | 빈칸과 누적 폐기 수량 |
| 엔딩 | 시간·수리 상태·통계 조회 | 게임 결과 UPDATE | 성공·실패 화면과 최종 통계 |

재료가 0개인 탐색은 보유 재료 INSERT 없이 시간·체력·통계 등을 UPDATE한다. 엔딩 판정과 재료 만료는 시간을 쓰는 행동마다 함께 확인한다.

### 발표용 데이터 변화 예시

1. 고물상 탐색으로 철 조각 3개를 얻는다. 보유 재료 묶음에 “철 조각 / 3개 / 인벤토리 / 세척 전” 행이 생성된다(CREATE).
2. 인벤토리를 열어 방금 생성한 행을 화면에 표시한다(READ).
3. 비행기 상자로 옮긴다. 동일한 행의 보관 위치가 상자로 변경된다(UPDATE).
4. 세척한다. 상태가 세척 완료로 바뀌고 세척액·체력·시간이 갱신된다(UPDATE).
5. 나머지 세척 재료도 준비한 뒤 엔진 시동 장치를 제작한다. 철 조각3개 묶음에서2개를 소비해 남은1개로 수정하고(UPDATE), 구리 전선2개·기어2개·배터리 셀1개도 소비한다. 전량 소비한 묶음은 DELETE한다. 수리 상태를 완료로 변경한다(UPDATE).
6. 새 상태를 조회하여 빈 슬롯과 수리 완료 표시를 화면에 반영한다(READ).

별도의 폐기 시연에서는 48시간이 지난 미세척 재료가 사용 불가로 바뀌는 UPDATE를 보여주고, 폐기 버튼으로 해당 행이 실제 삭제되는 DELETE를 보여준다. 발표할 때 행동 전후 DB 행과 게임 화면을 함께 비교하면 과제의 데이터 흐름을 명확하게 설명할 수 있다.

### 확장 기능의 DB 구성과 CRUD

| 추가 데이터 | 내용 |
| --- | --- |
| 탐색 장소·재료 관계 | 장소별 후보 재료·가중치·수량 규칙, 병원 확정 보급 |
| 게임 상태 확장 | 오염도·질병·발병 시각·치료 기한·연속 탐색 횟수·의료 키트 |
| 폭풍 일정 | 게임 ID, 폭풍 시작·종료 경과 시간 |
| 탐색 이력·획득 연결 | 탐색 ID, 장소·시간·노출·획득 결과 |
| 비밀의 방·열쇠 — 선택 확장 | 게임별 열쇠 수량·통계, 게임 ID와 장소 ID별 발견·개방 상태, 발견 시각·결과·보상·손실 내역 |

| 행동 | DB 처리 |
| --- | --- |
| 게임 시작 | 기존 게임·수리 대상 생성에 폭풍 일정 INSERT 추가 |
| 탐색 | 현재 상태·일정 READ, 획득 INSERT, 체력·시간·오염·질병·횟수 UPDATE |
| 병원 | 의료 키트 수량 UPDATE, 확률 획득 재료 INSERT |
| 휴식·치료 | 체력·시간·오염·연속 횟수·질병·의료 키트 UPDATE |
| 비밀의 방 발견·조회 | 게임·장소별 방 상태 INSERT 또는 발견 상태 UPDATE, 기억한 위치 READ |
| 방 입장·지나치기 | 발견·미개방·열쇠·체력 READ, 개방 상태·열쇠·시간·자원·통계 UPDATE |
| 방 추가 보상 | 재료 INSERT 또는 묶음 수량 UPDATE, 보급품 UPDATE |
| 방 재료 손실 | 남은 수량 UPDATE, 전량 손실 시 DELETE |
| 방 오염 결과 | 오염도·질병·통계 UPDATE |

방·열쇠 관련 테이블과 CRUD는 MVP 외 선택 확장이다. 일반 탐색에서 열쇠를 얻으면 수량·획득 통계를 UPDATE한다. 게임 ID와 장소 ID의 조합을 유일하게 관리해 방은 장소당 한 번만 개방한다. 발견 시 자동 입장하지 않으며 기억한 방이 있어도 다른 탐색을 허용한다. 입장 요청에서 개방 여부를 다시 확인하고 열쇠 소비와 결과 지급을 같은 트랜잭션으로 처리한다.

한 행동의 상태 변경·보상·손실·이벤트 처리는 동일 트랜잭션으로 묶는다. 무작위 결과, 체력과 시간, 오염과 질병, 재료 수량은 서버에서 계산한다. API는 최신 상태와 실행 가능 여부·제한 이유를 함께 제공한다.

## 13. 공통 처리 규칙

1. 진행 중인 게임인지 확인하고 최신 상태를 조회한다.
2. 행동 조건, 체력·공간·세척액·의료 키트·재료를 검증한다.
3. 불가하면 상태를 바꾸지 않고 제한 이유를 반환한다.
4. 시간·체력 비용과 결과를 반영한다. 탐색·방 입장에는 해당 시간 구간의 폭풍 영향을 계산한다.
5. 오염도·질병, 재료 만료와 통계를 갱신한다.
6. 240시간 이상 또는 질병 발생 후 72시간 이상 미치료라면 실패를 먼저 판정한다. 치료 완료가 기한에 도달한 경우에도 실패를 우선하며 성공 수리로 취소하지 않는다.
7. 제한 시간 내 모든 수리가 완료됐으면 성공을 판정한다.
8. 선택 확장 구현 시 종료되지 않은 일반 탐색에서 열쇠 획득과 해당 장소 미발견 방 발견을 독립 판정한다. 방 재방문은 일반 탐색 보상을 추가 지급하지 않는다.
9. 최신 상태·행동 가능 여부·비용·제한 이유를 화면에 반환한다.

시간 제한을 넘는 행동은 시작 전 안내하며 실행하면 실패한다. 엔딩 후에는 게임 행동을 막는다. UI의 회색 버튼과 별도로 서버에서도 조건을 검증한다.

오염·자원 소비·보상·이벤트 처리·시간·통계는 하나의 트랜잭션으로 반영하고 중복 요청으로 보상이나 수리가 반복되지 않도록 한다.

## 14. 난이도 조정 기준

10일·무작위 수리 4개·재료 10종·조합법 7개를 초기 기준으로 삼는다. 오염·질병·폭풍·비밀의 방 수치와 재료 분배는 아직 플레이 검증 전이다.

0개 획득 확률은 낮게 유지하고 필요한 일반·특수 재료를 넉넉하게 공급한다. 병원에서는 의료 키트를 확정 지급해 치료가 운에 막히지 않도록 한다.

어렵다면 필요한 재료 확률과 세척액 공급을 먼저 높이고, 조합 수량·질병 비용·폭풍 오염을 조정한다. 너무 쉽다면 우선 시간 배분과 재료 수요를 조정한다. 5개 수리 모드는 검증 후 검토한다.

확인할 항목: 무작위 고장 조합별 탈출률·소요 시간, 탐색 횟수, 특수 재료 부족, 세척액 부족, 저장 공간 포화, 묶음 6개 제한의 합치기·분할, 만료 손실, 질병 지속 시간·치료 방문, 폭풍 회피 가능성, 질병 72시간 치료 기한 내 회복 가능성. 선택 확장 구현 시 열쇠·방 획득 빈도, 입장 선택률과 손익을 추가 검증한다. MVP 밸런스는 방 보상 없이 탈출 가능한 상태로 먼저 확인한다.

시간이 즉시 진행되는 버튼 게임에서는 일수·조합만 늘려도 실제 플레이가 짧을 수 있다. 플레이 길이는 직접 측정하고 의사결정과 안내를 개선한다.

## 15. 개발 환경·현재 상태·한 달 일정

개발 환경: Java 17, Spring Boot, MySQL, HTML·CSS·JavaScript, IntelliJ IDEA, Git·GitHub. 개인 PC에서 개발하며 배포 환경은 추후 정한다.

기존 백엔드 1차 구현은 7일·재료 6종·부품 5종 중 3개 수리 규칙이다. 게임 생성·조회, 탐색, 보관 이동, 폐기, 휴식, 세척·만료, 제작·장착, 엔딩·통계를 구현했으며 앞선 MySQL 검증에서 테스트 30개가 통과했다. 사용자 IntelliJ 환경에서 서버 실행과 게임 생성 응답을 확인했다.

이번 문서의 10일·재료 확대·오염·질병·병원·폭풍·확장 UI는 MVP 추가 구현 대상이다. 비밀의 열쇠·비밀의 방과 관련 통계는 MVP 외 선택 확장으로, 기본 게임 검증 후 시간이 남으면 구현한다. 기존 테스트 결과가 확장 기능까지 검증했다는 뜻은 아니다.

## 19. 최신 화면·규칙과 전체 확률표 — 2026-10-31

기준일: <date start="2026-10-31" />. 기존 문서의 선택 확장으로 분류했던 비밀의 방은 현재 백엔드·화면 구현에 포함되어 있다. 아래는 현재 코드의 판정 기준이며 실제 플레이 균형은 추가 조정할 수 있다.

### 화면과 행동 표시

- 탐색 결과를 확인하면 메인 화면 대신 탐색 지역 선택 화면으로 돌아간다. 방을 발견하면 기존 발견 안내를 먼저 표시하고, 입장 결과 확인·나중에 방문·닫기 이후에도 탐색 지역 선택 화면으로 돌아간다. 게임 종료는 최종 결과 화면이 우선이다.
- 안전지대 정비 화면은 비행기 도면과 수리 패널을 하나의 묶음으로 가로·세로 가운데에 배치한다.
- 시간0h·체력 소모0·체력 변화0·오염 변화0은 행동 안내에서 생략한다. 실제 필요한 비용·회복량·기한 경고는 유지한다.
- 이동·세척·폐기·수리 완료 후 현재 보관함/정비 화면 유지. 휴식·치료 완료 후 야영지 복귀.
- 최대 체력15, 인벤토리4칸·상자16칸·한 묶음 최대6개. 시작 세척액1회분·최대10회분. 수리 대상4개는 각 총7개씩, 합계28개 재료가 필요하다.
- 기존 진행 중인 확장 규칙 판의 미수리 조합도 새7개 규칙으로 변경한다. 완료된 수리와 종료된 판·이전 규칙 판의 조합 기록은 유지한다.

### 탐색과 보급 확률

| 판정 | 확률 및 규칙 |
| --- | --- |
| 유효한 일반 탐색의 귀환 | 항상 완료. 아래 재료0개는 실패가 아니다 |
| 낮 총 재료 수량 | 0개5% / 1개15% / 2개35% / 3개45% |
| 밤 총 재료 수량 | 0개5% / 2개20% / 3개35% / 4개40% |
| 첫 재료 종류 | 해당 장소 후보N개에서 각1/N. 병원N=2, 나머지N=3 |
| 두 번째 재료 종류 | 총2개 이상일 때 첫 종류를 제외한N−1개에서 균등 선택. 중복 종류 없음 |
| 두 종류 사이 수량 배분 | 총수량T일 때 첫 재료1~T−1개를 각1/(T−1)로 선택. 나머지는 두 번째 재료 |
| 세척액 지급량 | 모든 일반 탐색에서1회분70% / 2회분30%. 재료0개와 독립, 보유량은10까지 |
| 의료 키트 | 일반 탐색은 병원에서1개 확정, 다른 장소는 지급 없음. 보유2개까지 |
| 비밀 열쇠 | 정상 종료 전 모든 일반 탐색에서10%로1개, 최대2개. 방 발견과 독립 |
| 새 방 발견 | 아직 미발견인 해당 장소의 방에15%. 이미 기억한 방은 재추첨으로 추가 발견되지 않음 |
| 한도 초과 | 보유량/빈칸에 따라 실제 저장량 감소. 별도의 추첨 확률이 아니다 |

의료 키트·세척액·열쇠는 재료 인벤토리를 차지하지 않는다. 일반 탐색의 재료 후보는 6절 표와 같다. 재료가2종이고 빈칸이1칸이면 첫 종류부터 저장하며, 두고 온 수량을 결과에 표시한다. 실패 엔딩에 도달하면 새 열쇠·방 발견 판정은 생략한다.

### 질병 확률

| 오염 반영 후 수치 | 새 발병 확률 |
| --- | --- |
| 0~59 | 0% |
| 60~79 | 30% |
| 80~89 | 40% |
| 90~100 | 60% |

일반 탐색과 비밀의 방 종료에만 판정한다. 이미 질병이 있으면 추가 발병·기한 갱신 없음. 일반 탐색 기본 오염+10, 연속3회째부터+5, 폭풍 겹친 시간당+5다. 휴식 시간당−5·의료 키트−60은 확정 효과이며, 휴식으로 질병이 제거되지는 않는다. 질병 미치료72h와 생존240h 제한은 유지한다.

### 비밀의 방 결과 확률

| 결과 | 전체 확률 | 상세 |
| --- | --- | --- |
| 재료 추가 | 50% | 해당 장소의 후보 한 종류 균등 선택, 3개/4개 각50%. 원래 재료 확률표와 별도 |
| 세척액 보급 | 15% | 2회분, 최대10까지 |
| 의료 키트 보급 | 15% | 1개, 최대2까지 |
| 재료 손실 | 10% | 입장 시 휴대 중인 미세척 재료를1개/2개 각50% 추첨 후 실제 보유량까지만 손실 |
| 추가 오염 | 10% | +15 |
| 손실 대상 없음 | 위 손실10%도 오염+15로 대체 | 따라서 미세척 휴대품이 없으면 재료 손실0%, 추가 오염20% |

입장 시 열쇠1개를 소비한다. 일반 탐색 보급/열쇠/발견 판정을 중복 실행하지 않는다. 좋은 결과 합계80%·나쁜 결과20%지만, 보유 한도와 빈칸에 따라 실제 받는 양은 줄어들 수 있다. 손실은 시작 묶음을 균등 선택하고 필요한 경우 다음 묶음으로 이어서 차감한다.

### 시작 무작위 요소와 폭풍

| 항목 | 분포 |
| --- | --- |
| 고장 부품 | 7종 중 중복 없이4종 균등 선택. 각4종 조합은1/35, 각 부품이 선택될 확률4/7(약57.14%) |
| 첫 폭풍 시작 | 경과24~48시간의 정수25개 중 균등 선택, 각4% |
| 다음 폭풍 시작 간격 | 직전 시작에서24~48시간, 각4% |
| 폭풍 지속 | 1/2/3시간 각1/3(약33.33%) |

폭풍 일정은 새 판 생성 시 만들고 경과240h 미만의 시작 시각만 등록한다. 실제 시간 타이머나 확률적인 수리 실패·세척 실패·휴식 실패는 없다. 조건을 만족한 행동은 성공 처리하며 만료와 엔딩은 행동 후 시간을 기준으로 결정한다.
